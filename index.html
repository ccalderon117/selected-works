02

BGA POLICY / INTERNAL EDITORIAL TOOL

Chicago Budget Graphics Generator

CIVIC DATA VISUALIZATION
PUBLISHING TOOL

From public budget data to publishable graphics.

I built a browser-based tool for BGA policy analysts to select a Chicago department and budget cycle, explore its finances and workforce, and export a consistent set of graphics for publication.

Explore the live tool ↗

The problem

Recurring budget analysis requires joining public data across changing department codes and names, then turning it into consistent graphics that editors can publish.

What I built

Integrated live City of Chicago APIs with BGA spending and vacancy extracts; normalized historical departments; and developed responsive, interactive SVG charts with source notes and explicit missing-data handling.

The publishing workflow

Analysts can download individual SVGs or a ZIP with frozen charts, HTML, shared styles, tooltip JavaScript, and an offline preview for an Astro site.

MY ROLE
API integration · Data normalization · Chart development · Interface design · Publishing exports
TOOLS
D3.js · HTML · JavaScript · CSS · SVG · City of Chicago open-data APIs

CURRENT SCOPE Budget floor and category-level actual spending graphics are placeholders. The 2027 preparation mode uses the 2026 ordinance as its baseline.

ILLINOIS ANSWERS PROJECT / BETTER GOVERNMENT ASSOCIATION

Beyond the original story.

ANALYTICS INFRASTRUCTURE
INTERNAL DATA PRODUCT

A republication analytics system.

I designed and developed a system to measure engagement with Illinois Answers stories republished on external websites, from event collection to structured data for reporting.

The problem

A story's reach extends beyond its original website. Understanding engagement on republishing sites requires a separate collection and reporting workflow.

What I did

Designed the event tracking, cloud pipeline, database structure, and SQL-based reporting foundation to connect stories with engagement data.

The outcome

Structured republication data provides a foundation for analyzing where stories are read and how readers engage with them.

MY ROLE
System design · Data collection · Database design · Analytics infrastructure
TOOLS
JavaScript · AWS Lambda · API Gateway · Supabase · SQL
